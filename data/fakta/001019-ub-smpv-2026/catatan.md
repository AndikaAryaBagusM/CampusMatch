# Catatan untuk pemeriksa

- **Tidak ada arsip Wayback (`arsip_url` kosong):** selma.ub.ac.id menolak permintaan non-peramban (403) dan Wayback Save Page Now gagal dengan HTTP 520 untuk setiap halaman (dicoba beberapa kali pada 2026-10-11). Pemeriksa perlu membuka halaman aslinya di peramban.
- Halaman SMPV (Seleksi Mandiri Vokasi dan PSDKU Kediri): nilai rapor dan prestasi, untuk Prodi Vokasi dan S1 PSDKU Kediri. Pendaftaran (pembayaran) 22 Juni – 7 Juli 2026, pemberkasan sampai 8 Juli 2026, pengumuman 13 Juli 2026.
- Biaya pendaftaran Rp500.000.
- Situs SELMA UB menolak unduhan langsung (403), jadi isi diambil lewat peramban.
- Halaman umum "Biaya Pendaftaran" (Rp500.000 untuk SMUB, SMPD, SMPV) tidak dicatat karena tidak menyebut tahun; tiap pengumuman jalur menyebut sendiri biaya pendaftarannya.
